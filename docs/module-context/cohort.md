## Module verification and resource focus

Ownership/lease and join cases; bounded specialist briefs; duplicate assignment, stale thread and parent integration counterexamples. These are tool/resource families to inspect or qualify; this card does not assert that engine commands or their collectors exist.

**Current test priorities:** ["thread/agent roster cohesion", "ownership and claim transfer", "join/fanout/cancellation", "parent verification and stale messages"]. The governing standard requires at least 50 distinct meaningful primary-owned cases, zero baseline warnings/errors, assimilation and mutation evidence. Read the exact language/threat profile rather than copying a generic test command.
