## Module verification and resource focus

SQL/migration review; SQLite configuration and checksum inspection; fault cut-points, restart and backup/restore controls. These are tool/resource families to inspect or qualify; this card does not assert that engine commands or their collectors exist.

**Current test priorities:** ["atomic writes and crash recovery", "idempotent replay", "schema migration/rollback", "stale writers and durable identity"]. The governing standard requires at least 50 distinct meaningful primary-owned cases, zero baseline warnings/errors, assimilation and mutation evidence. Read the exact language/threat profile rather than copying a generic test command.
