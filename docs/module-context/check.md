## Module verification and resource focus

Independent fixture/receipt inspection; wrong-subject, forged-report and intended-fault controls; protected collector and admission boundaries. These are tool/resource families to inspect or qualify; this card does not assert that engine commands or their collectors exist.

**Current test priorities:** ["independent oracle and exact subject", "zero/missing/skipped case refusal", "forged or stale evidence", "producer/collector custody and negative controls"]. The governing standard requires at least 50 distinct meaningful primary-owned cases, zero baseline warnings/errors, assimilation and mutation evidence. Read the exact language/threat profile rather than copying a generic test command.

Use [RB03](obsidian://open?vault=herdr-engineering-engine-v3.vault&file=Operations%2FRunbooks%2FRB03) for module qualification, [RB05](obsidian://open?vault=herdr-engineering-engine-v3.vault&file=Operations%2FRunbooks%2FRB05) for security and [RB04](obsidian://open?vault=herdr-engineering-engine-v3.vault&file=Operations%2FRunbooks%2FRB04) when packaging/recovery is affected. Independent oracles and protected raw evidence precede any admission claim.
