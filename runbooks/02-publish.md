**Owner:** corpus maintenance orchestrator. **Preconditions:** authorized documentation change, agreeing prior records, quiescent affected writers and known owning files. **Effects:** maintenance test evidence and journaled documentation writes including admitted diary navigation; no engine implementation.

1. Edit the narrow normative owner or generator and preserve authored changes.
2. Inspect the actual discovered maintenance case inventory. Run `./tools/corpus-sync --verify-tooling`; require all normal/optimized cases and raw diagnostics to pass.
3. Run `./tools/corpus-sync` and require staged parity, source-body protection, frozen before/after hashes and complete core records, followed by successful Graphify extraction and publication for that generation. A later graph failure leaves full-corpus closure unresolved even if a core PASS was printed.
4. Run `./tools/corpus-sync --check` and independently verify the changed module/facet/recipe routes.
5. Retain subject, generation, failures/dispositions and maintenance footprint.

**Failure/recovery:** stop on authored conflict, missing/changed source or failed check. For an interrupted core publication, review the journal named by its record under `ultra-map-review/publications` and use `./tools/corpus-sync --resume <reviewed-core-journal>`; replace the placeholder with that exact reviewed path. This route resumes core writes and then synchronizes and rebuilds the graph. If the core records are complete and only Graphify failed or was interrupted, inspect its retained diagnostics and use `./tools/corpus-sync --graph`, then `./tools/corpus-sync --check`. Graph journals under `ultra-map-review/graphify-20260915` are recovered by `--graph`, never passed to `--resume`. A stale graph recovery generation or authored conflict must be reconciled; do not delete pending evidence to bypass refusal. Never execute historical commands or repeat engine effects. **Budgets:** one synchronized writer; bounded source intake; tests use owned disposable directories. **Closure:** documentation convergence only, never engine admission.
