**Owner:** operator/orchestrator. **Preconditions:** known codebase/atlas/vault roots, readable current records, no claim of engine authority. **Effects:** local reads and corpus consistency check; no engine action.

1. Read README, quick start, completion standard and handoff.
2. Inspect the known generated Justfile as text before invoking it. Use `just --list` / `just --dump --dump-format json` only for this reviewed file; arbitrary recipes or preconditions may have effects.
3. Run `./tools/corpus-sync --check` from the host project root.
4. Require producer exit zero, `PASS current synchronized corpus` and nested `PASS current Graphify corpus projection`, all for the same complete generation. The core publication message alone is insufficient.
5. Select the relevant module stub and follow its tasks, interfaces, completion card and counter-evidence.

**Failure/recovery:** absent root or changed output is unresolved; restore access or reconcile the owner through RB02. Do not recreate/chown a missing sibling directory blindly. **Retain:** generation, exact checks, gaps and selected reading route. **Cleanup:** none beyond owned review files.
