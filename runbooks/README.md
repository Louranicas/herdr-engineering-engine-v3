The existing corpus synchronizer owns publication and verification. A small generated Justfile gives it discoverable aliases; Markdown runbooks define preconditions, effects, ordered steps, decisive results, failure/recovery, resources and evidence. Future engine procedures belong to the existing workflows/actions/task owners. These Markdown contracts are not automatically compatible with `habitat-runbook` TOML or a new executor.
