## Chain only for the current gap

Unknown owner → focused Prime → explicit handoff of question, exact paths/roles, required source AND relationship coverage, scope, cap and gaps → Habitat Context capture/packet if useful → selected module scout → reconcile/plan only when needed → authorized implementation/verification → context handoff.

When sources are known, skip fresh orientation. Budget omissions require selection or supplemental admissible reads; they do not automatically call for more vault discovery. Unsupported syntax needs interpretation; a denied source remains denied. Carry provenance, partial results and omissions across the handoff. Source inclusion can succeed while important relations are absent from packet routes—inspect only the relevant authenticated graph edges and disclose the additional reads. Budget discovery, supplements and repeated context as well as packet bytes.

The Toolshed comparison’s timings, scores and prior packet counts remain historical observations. They do not establish this module scout’s speed, answer quality or top-tail performance. Exact reviewed source captures and adoption limits are retained in the atlas evidence directory; the current installed skill remains the owner of each companion’s procedure.
